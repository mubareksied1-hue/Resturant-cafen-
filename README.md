# Cafen Café

Welcome to Cafen Café, a modern and elegant café website designed to provide visitors with a warm and welcoming online experience.

## About the Project

Cafen Café is a website created for a café business. It allows visitors to explore the café, view the menu, learn about events, make reservations, and contact the café.

## Features

* Home page
* Café menu
* Events section
* About Us section
* Table booking
* Contact page
* Café address and contact information
* Social media links
* Media and video section
* Newsletter subscription
* Responsive design

## Design

The website uses a warm café-inspired color palette including:

* Maroon
* Gold
* Cream
* Brown

The design focuses on simplicity, elegance, and a comfortable café atmosphere.

## Technologies Used

* HTML5
* CSS3
* Font Awesome
* Responsive CSS
* GitHub Pages

## Responsive Design

The website is designed to work on:

* Desktop computers
* Tablets
* Mobile phones
* iPhone 16 Pro Max

## How to View the Website

The website is hosted using GitHub Pages.

The website URL will look like:

```text
https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/
```

Replace `YOUR-USERNAME` with your GitHub username and `YOUR-REPOSITORY` with your repository name.
